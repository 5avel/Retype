# Manual test — M4 (convert selection)

Build: `cargo build --release -p retype`, run `target\release\retype.exe`.
Log: `%LOCALAPPDATA%\retype\retype.log`. Append results to
`docs/manual-test-log.md`.

Setup: en-US and ru-RU installed, default config (or your own
`convert_selection` hotkey, e.g. `Ctrl+Shift+C`). Before each case copy the
word `MARKER` to the clipboard; after each case paste it to check the
clipboard was restored.

## Scenarios (Notepad first)

| #  | Do                                                       | Expected                                                     |
|----|----------------------------------------------------------|--------------------------------------------------------------|
| 1  | Select `ghbdtn`, selection hotkey                        | `привет`; layout RU; clipboard still `MARKER`                |
| 2  | Select `Ghbdtn? vbh!`                                    | `Привет, мир!`                                               |
| 3  | Layout EN, select `руддщ`                                | `hello` (source detected from the text)                      |
| 4  | Select two lines `ghbdtn` / `vbh`                        | Both lines converted, line break kept                        |
| 5  | Nothing selected, hotkey                                 | Nothing changes; log `NothingSelected`; clipboard `MARKER`   |
| 6  | Select `12345`                                           | Nothing changes; log `NothingToConvert`                      |
| 7  | Copy an image (Paint) instead of `MARKER`, then test 1   | Converted; the image is pasteable again afterwards           |
| 8  | Win+V history on: run test 1, open Win+V                 | Only the copied `ghbdtn` appears, not `привет` (ADR-011)      |
| 9  | Hotkey with Ctrl/Shift, tap quickly                      | Correct; no stuck Ctrl/Shift; no stray letter typed          |
| 10 | Hold the selection hotkey ~2 s                           | Converts once                                                |
| 11 | `switch_layout_after_convert = false`, test 1            | `привет`, layout stays EN                                    |
| 12 | Search the log for the converted words                   | Not found (P4)                                               |
| 13 | Win+L, unlock, then type and use the word hotkey         | Works; typing is not treated as Ctrl/Alt combos              |
| 14 | Do test 1, then Tray → Exit at once                      | Exits within ~1 s; clipboard still `MARKER`                  |
