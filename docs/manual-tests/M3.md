# Manual test — M3 (convert last word / line)

Build: `cargo build --release -p retype`, run `target\release\retype.exe`.
Log: `%LOCALAPPDATA%\retype\retype.log`. Append results to
`docs/manual-test-log.md`.

Setup: en-US and ru-RU installed, default config. Without a `Pause` key, bind
the hotkeys in the config (e.g. `convert_last_word = "Ctrl+Shift+Z"`,
`convert_last_line = "Ctrl+Shift+X"`). Start each case in the EN layout.

## Scenarios (Notepad first)

| #  | Do                                                     | Expected                                                              |
|----|--------------------------------------------------------|-----------------------------------------------------------------------|
| 1  | Start retype                                           | Log: `N keyboard layouts installed`, no `not installed` warning       |
| 2  | Type `ghbdtn`, word hotkey                             | `привет`, layout is now RU; log `converted LastWord, 6 keys`          |
| 3  | Press the word hotkey again                            | `ghbdtn`, layout back to EN (toggle)                                  |
| 4  | Type `Ghbdtn`                                          | `Привет` (Shift kept)                                                 |
| 5  | Type `ok ghbdtn ` (trailing space), word hotkey        | `ok привет ` — only the last word, space kept                         |
| 6  | Type `ghbdtn vbh`, line hotkey                         | `привет мир`                                                          |
| 7  | Type `;bpym`, word hotkey                              | `жизнь` (punctuation keys are letters)                                |
| 8  | In RU type `руддщ`, word hotkey                        | `hello`, layout EN                                                    |
| 9  | Type `ghbdtq`, Backspace, `n`, word hotkey             | `привет`                                                              |
| 10 | Type a word, click in the text, word hotkey            | Nothing changes; log `nothing to convert`                             |
| 11 | Hold the word hotkey ~2 s                              | Converts once, no flicker back and forth                              |
| 12 | Hotkey with Ctrl/Shift (e.g. Ctrl+Shift+Z), keep held  | Correct text; after release no stuck Ctrl/Shift                       |
| 12a| Same hotkey, tap it quickly (release at once)          | Correct text; Ctrl/Shift not stuck (type a letter to check)           |
| 13 | Bind a hotkey with Win or Alt, use it                  | Converts; Start menu / window menu does not open                      |
| 14 | `switch_layout_after_convert = false`, restart, test 2 | `привет`, layout stays EN; also in Word and VS Code (slow apps)       |
| 15 | `layouts = ["en-US", "de-DE"]` (de not installed)      | Log warns at start; hotkey does nothing, text untouched               |
| 16 | Search the log for a word you typed                    | Not found (P4)                                                        |
