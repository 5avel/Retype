# Manual test — M2 (Windows skeleton)

Build: `cargo build --release -p retype`, run `target\release\retype.exe`.
Log: `%LOCALAPPDATA%\retype\retype.log`. Append results to
`docs/manual-test-log.md`.

| #  | Step                                                         | Expected                                                                                                                 |
|----|--------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------|
| 1  | Start retype                                                 | Tray icon appears, tooltip "retype"; log has `starting`, `hooks installed`, `worker started`                             |
| 2  | Start a second `retype.exe`                                  | It exits at once; one tray icon; log has `another instance is running`                                                   |
| 3  | Type in Notepad for a minute                                 | Typing feels normal, no lag; log has no typed text                                                                       |
| 4  | Type `ghbdtn`, press `Pause`                                 | Nothing changes in Notepad (M3), Pause key is not passed to the app; log: `convert LastWord requested (6 keys buffered)` |
| 5  | Type a word, click with the mouse, press `Pause`             | Log: `0 keys buffered`                                                                                                   |
| 6  | Type a word, Alt+Tab to another window and back, `Pause`     | Log: `0 keys buffered`                                                                                                   |
| 7  | Type a word, wait 35 s, press `Pause`                        | Log: `0 keys buffered` (idle reset)                                                                                      |
| 8  | Press `Ctrl+Pause`                                           | Tooltip "retype — paused", log `paused`; `Pause` now reaches apps, no `convert` lines                                    |
| 9  | Tray → Resume                                                | Tooltip "retype", log `resumed`                                                                                          |
| 10 | Tray → Open config (no config yet)                           | `%APPDATA%\retype\config.toml` is created from the example and opens in an editor                                        |
| 11 | Put `mode = "auto"` in the config, restart retype            | Runs with defaults; log has `config syntax error` naming the line                                                        |
| 12 | Tray → Open log folder                                       | Explorer opens `%LOCALAPPDATA%\retype`                                                                                   |
| 13 | Restart Explorer (Task Manager → Windows Explorer → Restart) | Tray icon comes back                                                                                                     |
| 14 | Tray → Exit                                                  | Icon disappears at once, process ends; log has `hooks removed`, `worker stopped`, `exit`                                 |
| 15 | Search the whole log for a word you typed                    | Not found (P4)                                                                                                           |
