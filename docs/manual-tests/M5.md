# Manual test — M5 (exclusions, autostart, config reload)

Build: `cargo build --release -p retype`, run `target\release\retype.exe`.
Log: `%LOCALAPPDATA%\retype\retype.log`. Append results to
`docs/manual-test-log.md`.

## Exclusions

Put `processes = ["notepad.exe"]` under `[exclusions]` in the config (the
reload picks it up within ~2 s).

| #  | Do                                                       | Expected                                                   |
|----|----------------------------------------------------------|------------------------------------------------------------|
| 1  | Notepad: type `ghbdtn`, word hotkey                      | Nothing converted; the hotkey reaches Notepad              |
| 2  | Notepad: selection hotkey on a selected word             | Nothing converted; clipboard untouched                     |
| 3  | Notepad: `Ctrl+Pause` (or your pause hotkey)             | retype pauses (tray tooltip); pause stays global           |
| 4  | Switch to another app (e.g. browser), type and convert   | Works there                                                |
| 5  | Back to Notepad, type and convert                        | Excluded again                                             |
| 6  | Search the log for `notepad`                             | Not found (process names are never logged)                 |

## Config reload

| #  | Do                                                       | Expected                                                   |
|----|----------------------------------------------------------|------------------------------------------------------------|
| 7  | Change `convert_last_word` to another hotkey, save       | Log `config reloaded` within ~2 s; new hotkey works, old one reaches apps |
| 8  | Break the file (`mode = "auto"`), save                   | Log `config not reloaded: …`; previous hotkeys still work  |
| 9  | Fix the file, Tray → Reload config                       | Log `config reloaded`                                      |
| 10 | Set `[log] level = "debug"`, save                        | Debug lines appear (e.g. `foreground app excluded`)        |
| 11 | Reload while paused                                      | Stays paused                                               |
| 11a| Rename the config file away and back within 2 s          | Settings unchanged (a briefly missing file is ignored)     |

## Autostart

| #  | Do                                                       | Expected                                                   |
|----|----------------------------------------------------------|------------------------------------------------------------|
| 12 | Open the tray menu                                       | "Start with Windows" unchecked (default off)               |
| 13 | Click it, open the menu again                            | Checked; `regedit` shows `HKCU\…\Run\retype` = `"<path>\retype.exe"` |
| 14 | Sign out and in (or reboot)                              | retype starts, one tray icon                               |
| 15 | Exit, move `retype.exe` elsewhere, start it from there   | Log `autostart path updated`; the Run value has the new path |
| 15a| Exit, start a copy from another folder (old exe remains) | Run value unchanged                                        |
| 16 | Click "Start with Windows" again                         | Unchecked; the Run value is gone                           |
